# tarea_lambdas

Daniel Andre Bañuelos

## Descripcion

Tarea de lambdas de POO. Son 2 clases con metodos static, OperacionesNumeros para numeros y OperacionasCadenas para cadenas, y el Main donde se prueban todos.

## Metodos

1. multiplicar - multiplica cada numero de la lista por un factor con replaceAll
2. filtro - borra las palabras que empiezan con una letra o que tienen menos de n letras con removeIf
3. mayusculas - pasa las palabras a mayusculas con stream y map
4. cuadrados - guarda los cuadrados de los numeros pares en un HashSet
5. longitudes - hace un HashMap con cada palabra y su longitud con toMap
6. catalogo - imprime los productos con 10% de descuento con forEach
7. frecuencias - cuenta cuantas veces sale cada palabra con merge
8. clasificar - deja las palabras con frecuencia mayor o igual al minimo con entrySet().stream()
9. sinRepetir - separa una frase y guarda las palabras en minusculas en un HashSet
10. tope - si una frecuencia es mayor a n la deja en n con replaceAll
